# SolidityGlance

SolidityGlance is a decentralized data management framework for executing smart contracts efficiently with modular library support.

SolidityGlance is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- SolidityGlance is a decentralized data
- management framework for executing smart
- contracts efficiently with modular library

## Technology Stack

- javascript
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/SolidityGlance.git`
2. `cd SolidityGlance`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
